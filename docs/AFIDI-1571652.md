# AFIDI 1571652 — pallets atuais para Uruguay

O proprietário confirmou em 06/10/2026 que o AFIDI **1571652** corresponde a todos os pallets atuais em preparação para Uruguay. O certificado fica salvo no campo `metadata.export_label.afidi` de cada pallet e aparece na prévia, na impressão A4 paisagem, no PDF e no card de consulta interna.

## Aplicação no banco

Executar o arquivo completo `supabase/operations/20261006_afidi_1571652_uruguay.sql` no SQL Editor do projeto **znbtwkhktlldzhkiwodu**. É uma operação pontual com dados reais; não faz parte das migrações automáticas, não cadastra dados de demonstração e não cria um padrão para os próximos pallets.

Para o ambiente em que a atualização anterior de recepções/tara/Piris ainda precisa ser aplicada, foi preparado o arquivo local único `outputs/ACTIVAR-RECEPCIONES-TARA42-PIRIS-AFIDI1571652-20261006.sql`. Ele reúne as atualizações já autorizadas e este preenchimento na mesma transação, verifica a identidade de `piris@adm.com` e preserva os demais perfis. Não é necessário executar os dois arquivos.

A operação alcança somente a Cooperativa Agronorte (`20000000-0000-4000-8000-000000000001`), pallets criados até **06/10/2026 14:19:13, America/Asuncion**, com destino confirmado `Uruguay`, em estados `En armado`, `Etiquetado` ou `Listo para carga`, sem vínculo com expedição. Destinos pendentes precisam ser confirmados no próprio sistema antes de receberem o certificado; não são presumidos pelo SQL.

São preservados os outros campos da etiqueta, dados de origem, peso líquido, peso bruto, tara, códigos e tokens de QR. Alterações são registradas na auditoria com os valores antes/depois e a justificativa da confirmação do proprietário. O registro identifica o operador real disponível ao banco; uma operação do SQL Editor não é atribuída artificialmente a Piris.

Pallets cuja etiqueta mudou voltam a `En armado` para exigir nova impressão. Reexecutar o arquivo não duplica alterações ou logs para pallets já confirmados, nem inclui pallets posteriores ao corte. A revisão da organização é incrementada uma vez quando existem alterações, permitindo detectar dados antigos em outros dispositivos.

## Conferência e impressão

1. Conferir no resultado do SQL os códigos com `AFIDI confirmado` e número `1571652`. Os excluídos do escopo aparecem com a razão.
2. No aplicativo conectado, sincronizar/atualizar os dados antes de imprimir. Se houver rascunhos locais pendentes, preservá-los e conciliá-los; não apagar os dados do navegador.
3. Entrar em **Pallets**, selecionar o produtor e conferir **AFIDI: 1571652**.
4. Abrir **Etiqueta / QR** e gerar novamente o PDF ou a impressão A4 paisagem. Etiquetas físicas e PDFs emitidos anteriormente precisam ser substituídos.

O código de QR permanece o mesmo. A página pública do QR continua expondo apenas as informações básicas autorizadas; a identificação AFIDI é impressa diretamente na etiqueta. Este ajuste não confirma códigos oficiais de produtor, datas de envasado ou certificação SENAVE que ainda não tenham sido informados.
